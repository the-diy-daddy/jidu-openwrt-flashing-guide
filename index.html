01Understanding the OpenWrt flash process

🔍
1

Router model

Identify your router's family: 6101, 6j01 or 6j11.

💾
2

Stock firmware

Check the version it runs. 6101 supports all; 6j01 and 6j11 need R3.2 or below.

🔓
3

Getting SSH access

Try the password trick first, if fails then the breeze.sh method.

📶
4

Flashing OpenWrt

Flash via SSH, or via UART where the process calls for it.
